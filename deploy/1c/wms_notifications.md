# Уведомления MOVA при создании реализации WMS

## Роль

Получатели определяются по роли мобильного приложения:

`ПолучатьУведомленияОтWMS`

## Вызов из WMS

Создать общий модуль `ИнтеграцияIntelligence`:

- включить `Сервер`;
- включить `Привилегированный`, чтобы фоновая интеграция могла читать получателей и записывать события;
- не включать `Клиент` и `Вызов сервера`, так как модуль вызывается только серверным кодом WMS.

В модуль целиком скопировать содержимое файла:

`deploy/1c/Integration_Intelligence_Server.bsl`

Добавить вызов сразу после успешной записи реализации:

```bsl
Попытка
	ИнтеграцияIntelligence.УведомитьОСозданнойРеализацииWMS(РеализацияБУ);
Исключение
	ЗаписьЖурналаРегистрации(
		"WMS.MOVA.Notification",
		УровеньЖурналаРегистрации.Ошибка,
		,
		ОписаниеОшибки()
	);
КонецПопытки;
```

Процедура принимает как объект, так и ссылку документа.
Модуль HTTP-сервиса `mova_api` менять для вызова из WMS не требуется.

## Что происходит

Для каждого пользователя с ролью:

1. Создаётся событие `wms_invoice_created`.
2. Отправляется push с просьбой распечатать накладную.
3. В payload записываются UID, номер и тип документа.
4. Повторный вызов для того же документа и пользователя не создаёт дубль.
5. Результат записывается в журнал регистрации `MOVA.WMS.InvoiceCreated`.
